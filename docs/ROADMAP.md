# Roadmap

The initial release proves specification-driven adaptation across independent hosts and adds a reviewable path from a missing capability to a sandboxed plugin. Further work is prioritized as follows:

1. Extend the signed sandbox catalog with publisher namespace policies and richer tools to author and assess extension proposals. Keep artifact generation and installation separate.
2. Add a production transactional storage adapter with cross-process event claims and an outbox for effects.
3. Expand IDSS layout, declarative form validation, task data bindings and workflow compensation.
4. Add protocol conformance fixtures and wider coverage for MCP resources, interactive A2UI and streamed AG-UI events.
5. Provide a native iOS example app with authenticated event transport and an expanded mobile compatibility matrix.
